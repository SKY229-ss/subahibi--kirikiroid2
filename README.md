# Subahibi for Kirikiroid2

An experimental adaptation of **Wonderful Everyday (Subahibi)** for Kirikiroid2 on macOS.

## Project Status

The local adaptation has reached revision 14. The work currently isn't finished, several bugs still appear in the game itself, fix will be done as soon as possible.


## Features

- BGI scenario execution adapted to a KAG-based runtime.
- Save/load menus, quick saves, configuration, auto mode, and skip controls.
- Chapter selection and gallery interfaces.
- Chinese afterstory text and choices integrated in the local build.
- Separate font handling and legacy bookmark compatibility.
- Music preview channel management and ending return flow.

## Compatibility

The local build targets Kirikiroid2 running through PlayCover on macOS.

## Known Issues

- Reported unexpected audio remains under investigation.
- The exit confirmation dialog requires a verified fix.
- Some complex visual effects and the original backlog interface remain incomplete.
- End-to-end testing across every route is still pending.

## Validation

Local checks covered 48 route cases, menu behavior, legacy afterstory bookmarks, ending control flow, and archive integrity. These checks do not establish complete visual or audio fidelity.
